# Terrevo Requirements

Format: `TRV-<DOMAIN>-<NNN>`

Examples:
- TRV-TOUR-001: MR shall start a daily tour.
- TRV-TOUR-002: System shall prevent more than one active daily tour per MR.
- TRV-TOUR-003: System shall calculate tour duration from trusted events.
- TRV-TS-001: System shall generate a daily timesheet from work events.

Tests should reference requirement IDs where practical.
Do not implement untracked business behavior merely because it appears useful.
