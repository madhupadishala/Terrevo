# Sprint 12 — Daily Timesheet

Status: CLOSED

- **TRV-DTS-001** — A submitted tour automatically generates one daily timesheet.
- **TRV-DTS-002** — Start/end and total worked minutes come only from trusted tour execution timestamps.
- **TRV-DTS-003** — Visit minutes are derived only from checked-out visit timestamps.
- **TRV-DTS-004** — Call count is derived from completed field visits.
- **TRV-DTS-005** — Time without a proven activity category is reported as unclassified, not fabricated as travel/meeting/admin.
- **TRV-DTS-006** — The MR may review once and add an optional remark; calculated work values are immutable.
- **TRV-DTS-007** — Review is idempotent by operation UUID.
- **TRV-DTS-008** — Owner/team read access follows existing execution/team scope.
