# Terrevo

Terrevo is a greenfield field-force automation platform.

This repository is intentionally bootstrapped with strict change-control rules before product feature development begins.

## Build principle

**Plan → isolate → build → test → review → freeze → integrate.**

Product features will be developed through scoped sprint branches and pull requests. Direct feature development on `main` is prohibited by repository policy.
